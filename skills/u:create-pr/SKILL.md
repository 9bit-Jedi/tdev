name: u:create-pr
description: "Create a GitHub PR for the current branch with a crisp, template-conformant description. Use when the user says \"create a PR\", \"open a PR\", \"make a pull request\", or similar, after work is committed."
---

Work is committed. Create a PR: title = last commit message. Read the actual diff before writing the description — never guess what changed. Figure out length of PR description on the basis of scale of change it makes. Try to keep it very crisp and to-the-point. Never push or commit without explicit confirmation first. Follow @.github/PULL_REQUEST_TEMPLATE.md format; include every checkbox, check only the ones done/relevant, leave the rest unchecked. Omit "generated by claude" and Claude as commit author.

# PR Merge Notification — Non-Technical Slack

Create a **short, clear Slack message** notifying the non-technical team about the current PR being merged.

### Format

* **🚀 Update:** One-line summary of what changed and why it matters.
* **📌 Relevant:** Leave placeholders for relevant sheets, docs, pages, dashboards, etc.
* **👥 Teams:** Tag relevant teams/people where needed.
* Keep it **non-technical, concise, and professional**.
* Use only a few formal emojis: 🚀 📌 👥 ✅
* Use **bold** for key information; avoid excessive formatting.
[Optional: **Next step:** [Action, if any]]
